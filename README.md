# CARD BATTLE - Render公開用完成版

2～4人で遊ぶターン制オンラインカードゲームです。

## 必要環境

- Node.js 20以上
- npm

## ローカル起動

```bash
npm install
npm start
```

ブラウザで `http://localhost:3000` を開きます。

## Renderへの公開

1. このフォルダをGitHubリポジトリへアップロード
2. Renderで「New → Web Service」
3. GitHubリポジトリを選択
4. Build Command: `npm install`
5. Start Command: `npm start`
6. Node.jsランタイムでデプロイ

Renderから指定される `PORT` をサーバーが自動使用します。

## オンライン仕様

- 2～4人
- アカウント・データベースなし
- プレイヤー名は入室時に設定
- ルームコードで参加
- ゲーム状態・ルール判定はサーバー側
- 切断後60秒以内なら再接続可能
- 60秒以内に復帰しなければその対戦を無効化
- サーバー再起動時はメモリ上のルームが消える
- 再戦機能あり

## 注意

この版は「普段遊ぶ友人4人程度」の用途を想定しています。
Renderのサーバー再起動や無料サービス停止が発生した場合、メモリ上のゲームは失われます。
